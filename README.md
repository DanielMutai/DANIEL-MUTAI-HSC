# Daniel Mutai, HSC — Service to Humanity

A polished, evidence-led public portfolio for Daniel Mutai, HSC, presenting his personal story, humanitarian impact, projects, recognition, media record and the Daniel Mutai Foundation.

## Site structure

- `index.html` — homepage and impact passport
- `pages/story.html` — first-person story and service timeline
- `pages/impact.html` — impact indicators and programme pillars
- `pages/projects.html` — project and programme records
- `pages/recognition.html` — recognition record
- `pages/foundation.html` — Daniel Mutai Foundation
- `pages/media.html` — press, broadcast and supplied photographs
- `pages/evidence.html` — current evidence record and future Foundation records
- `pages/contact.html` — partnership, support, media and documentation contact

## Current source material

The portfolio uses the supplied Foundation banner, supplied photographs, the supplied project photo record and the published Nation Media Group feature. The TUKO interview link supplied for the portfolio is included on the Media page.

## Design principles

The site uses a restrained editorial design: strong typography, high-contrast green sections, warm paper backgrounds, minimal decoration, clear navigation and evidence-focused presentation.

No personal ID numbers, dates of birth or private referee contact details are published.
